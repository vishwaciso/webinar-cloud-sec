1️⃣ What is Cloud Security?

Cloud Security is the practice of protecting cloud infrastructure, services, applications, identities, and data from misconfigurations, attacks, and data breaches.

Why Cloud Security is Critical?

  • Shared Responsibility Model
  • Misconfigurations cause 80%+ breaches
  • Compliance requirements (ISO, SOC2, HIPAA, PCI)
  • Identity is the new perimeter

4️⃣ What is Prowler?

Prowler is an open-source Cloud Security Posture Management (CSPM) tool used to assess AWS environments against security best practices and compliance frameworks.

Why Prowler?

  • Agentless
  • Open-source
  • Auditor-friendly reports
  • Supports multiple frameworks

5️⃣ Frameworks Supported by Prowler

FrameworkPurpose
CIS AWSBaseline security controls
ISO 27001Information security management
SOC 2Trust service criteria
NISTRisk-based security
PCI-DSSPayment security
HIPAAHealthcare data protection

6️⃣ Prowler Architecture

  1. Uses AWS API calls (read-only)
  2. Assumes IAM Role / AWS credentials
  3. Scans resources region-wise
  4. Maps findings to compliance controls
  5. Generates HTML / CSV / JSON reports

7️⃣ Installing Prowler (Practical)

🔹 Using Git

git clone https://github.com/prowler-cloud/prowler.git cd prowler pip3 install -r requirements.txt

🔹 Using Docker (Recommended)

docker run --rm -it -v ~/.aws:/root/.aws prowler/prowler aws

8️⃣ Running Prowler on AWS

Default Scan

./prowler aws

Specific Framework (CIS)

./prowler aws -f cis

Specific Region

./prowler aws -r us-east-1

Specific Account via Role

./prowler aws --role arn:aws:iam::123456789012:role/AuditRole

1️⃣1️⃣ Remediation Examples

S3 Public Access

  • Enable Block Public Access
  • Use IAM policies
  • Enable encryption

IAM MFA

  • Enable MFA
  • Remove long-term access keys
